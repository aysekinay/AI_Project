# AI Project: Genetic Algorithm Optimization

## Overview
This project explores genetic algorithms for solving optimization problems using Python.

## Methods
- Tournament selection
- Roulette wheel selection
- Crossover
- Mutation
- Fitness evaluation and result visualization

## Technologies
- Python
- Genetic Algorithms
- Data Visualization

## Team Project
This project was developed collaboratively by two students as part of an academic assignment.

## Learning Outcomes
The project provided practical experience with optimization algorithms, evolutionary computation, and collaborative programming.
